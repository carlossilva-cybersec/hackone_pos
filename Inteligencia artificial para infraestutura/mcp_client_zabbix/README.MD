Chatbot Inteligente para Zabbix MCP
Este projeto implementa um chatbot completo projetado para atuar como uma interface inteligente entre o Zabbix e o MCP (Model Context Protocol), incorporando capacidades avançadas de IA operacional.

🧩 Funcionalidades Principais
💬 Interação direta com o MCP do Zabbix — permite comunicação em tempo real com o servidor e agentes.
🧠 Integração com o DeepSeek — utiliza modelos de linguagem para análise contextual e respostas inteligentes.
⚙️ Agente de IA autônomo — executa tarefas, interpreta alertas e auxilia na automação de processos dentro do ambiente de monitoramento.

🚀 Objetivo
Fornecer uma camada de inteligência conversacional e automação sobre o Zabbix, elevando o nível de observabilidade, análise e resposta em ambientes de AIOps e SOC NextGen.
