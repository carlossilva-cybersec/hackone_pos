# Repositório de Ferramentas – Aula Prática

Este repositório reúne **ferramentas, projetos e forks** utilizados durante as aulas práticas, com foco em **segurança da informação, pentest, CTI e estudos ofensivos/defensivos**.

O objetivo é centralizar os materiais utilizados em laboratório, facilitando o acesso, a reprodução dos testes e o aprofundamento técnico dos alunos.

## Estrutura do Repositório

Cada diretório pode conter:
- Ferramentas open source
- Forks de projetos públicos
- Scripts de apoio
- Ambientes de laboratório
- Exemplos práticos utilizados em aula

Sempre que aplicável, os **créditos e links para os projetos originais** são mantidos nos respectivos diretórios.

## Aviso Importante

Este repositório é destinado **exclusivamente para fins educacionais, estudo e laboratório**.

⚠️ **Não utilize as ferramentas aqui contidas em ambientes de produção ou sem autorização formal.**  
O uso indevido pode violar leis, políticas internas e boas práticas de segurança da informação.

## Créditos

Todos os projetos e ferramentas pertencem aos seus respectivos autores.  
Este repositório **não reivindica autoria** sobre códigos de terceiros, atuando apenas como um agregador educacional.
